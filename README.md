# Customer Management System

Python project that simulates a simple customer and project management system using dictionaries and basic data analysis.

## Features
- Customer data storage and lookup
- Service pricing system
- Project tracking per customer
- Cost calculations based on hourly rates
- Service usage analysis
- Financial summaries and budget analysis
- Customer validation and reporting
- Service recommendation system

## Tech Stack
- Python

## How to Run
1. Run the script:
   python customer_management.py

## Key Insights
- Tracks total project hours and budgets
- Identifies most used services
- Highlights highest and lowest budget projects
- Shows active customers and their workloads
- Recommends services based on past usage

## Purpose
Built to practice dictionaries, loops, conditionals, and basic business logic in Python.
